Pruebas realizadas

  1. Primer ajuste. El equipo subió el pH y bajó la temperatura. Observó que morían demasiadas bacterias.
  2. Cambio de estrategia. Subió la temperatura y ajustó el pH tomando como referencia los valores que había consultado en repositorios bacteriológicos.
  3. Lote infectado. Para que el lote sobreviviera, añadió plástico y filtró el MHET que se había producido.
  4. Alimentación posterior. Siguió añadiendo plástico para que el lote tuviera alimento.

Monitor de estado

Desde Bash, con curl y jq instalados, define la URL base del reto (sin barra final) y el token de tu equipo. Estos valores sirven para ambos scripts.

read -rp 'URL base del reto: ' BIO
read -rsp 'Token del equipo: ' TOKEN
printf '\n'
export BIO TOKEN

Ejecuta bash estado.sh en esa terminal. El monitor muestra el JSON en color, omite cinco campos y espera dos segundos entre consultas. Pulsa Ctrl + C para detenerlo.

clear
while true; do
  datos=$(curl -s "$BIO/api/equipo/estado" \
    -H "Authorization: Bearer $TOKEN" |
    jq -C 'del(.equipo, .evento, .prueba, .escala, .ritmo_min_s)')
  printf '\033[H%s\033[J' "$datos"
  sleep 2
done

La bitácora recoge este alias de Bash para enviar JSON al equipo mediante POST.

alias api='curl -s -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" -X POST'

El nombre de la acción va en el campo tipo del JSON. Por ejemplo, para medir el pH con el alias anterior:

api "$BIO/api/equipo/accion" -d '{"tipo":"medir_ph"}'

Con el script descargable, la misma petición se envía con bash accion.sh medir_ph.

Peticiones registradas

El script accion.sh envía una petición por ejecución. Elige el comando según la acción que quieras aplicar al equipo.

Añadir plástico en (300, 250)
bash accion.sh plastico
{"tipo":"plastico","x":300,"y":250}
Subir la temperatura una unidad
bash accion.sh temperatura
{"tipo":"temperatura","delta":1}
Filtrar
bash accion.sh filtrar
{"tipo":"filtrar"}
Aplicar un ajuste de búfer de −1
bash accion.sh buffer
{"tipo":"buffer","delta":-1}
